# Assistant Systems — Justin-os Brief

2026-11-24 · Justin

justin-os is Justin's personal assistant system. It keeps notes, tasks, and a conversation log in one workspace, and it produces one weekday morning brief across the connected inboxes and calendars. This file is the public record of that system. It is not a validated product.

## Who uses it, and when

Justin uses it at the start of a weekday. Sandra, a standing assistant in the chief-of-staff role, keeps the workspace and delivers the brief in chat. A second standing assistant, Product Lead, holds per-product and per-client vision. Architect, designer, and coder are not standing assistants. Each is a cloud agent started for one job.

## What it must make possible

One read-only weekday brief, instead of starting the day across two Gmail accounts and two Google Calendar accounts with no single brief. A shared workspace for notes, tasks, and the conversation log. Drafts that are not sent unless Justin approves them. Design documents for the practice, written in this repository by pull request.

The account addresses are not written here.

## Out of scope

- Sending, labeling, archiving, or trashing mail, and editing calendar events or GitHub items, from the morning brief. The brief is read-only.
- A build repository. That comes later, when there is running config worth versioning.
- Client names, account addresses, and job-search details. This repository does not hold them.
- Product work and the website pilot. Both were paused on 2026-11-24 at 5:13 PM ET.
- A second assistant system. None is chosen.

## Open

- A named tool this system replaces, beyond the unbundled morning across those accounts, is not in the record. Justin decides whether to name one.
- The success measures in [plan.md](plan.md) are proposed. Justin confirms them.
